# Screenshots Folder Guide

As specified in the lab exam instructions, save the following screenshots into this directory:

1. `01_http_server_running.png` - Terminal output of `node httpServer.js` (Port 3000)
2. `02_http_welcome_route.png` - Browser output for `http://localhost:3000/`
3. `03_http_fs_home_page.png` - Browser output demonstrating static file serving using FS module at `http://localhost:3000/home`
4. `04_http_get_tasks.png` - Browser / EchoAPI output for `http://localhost:3000/tasks`
5. `05_http_post_add_task.png` - EchoAPI screenshot demonstrating `POST http://localhost:3000/add-task`
6. `06_express_server_running.png` - Terminal output of `node expressApp.js` (Port 4000)
7. `07_echoapi_get_all_tasks.png` - EchoAPI screenshot for `GET http://localhost:4000/tasks`
8. `08_echoapi_get_task_by_id.png` - EchoAPI screenshot for `GET http://localhost:4000/tasks/1`
9. `09_echoapi_post_new_task.png` - EchoAPI screenshot for `POST http://localhost:4000/tasks` (Status 201)
10. `10_echoapi_put_update_task.png` - EchoAPI screenshot for `PUT http://localhost:4000/tasks/1`
11. `11_echoapi_delete_task.png` - EchoAPI screenshot for `DELETE http://localhost:4000/tasks/1`
12. `12_github_commit_history.png` - GitHub commit history screenshot

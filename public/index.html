Employee Task Management System

A lightweight and high-performance task management application developed with Node.js and Express.js.

Project Overview

This platform manages employee workflows, tasks, priorities, and assignments. It demonstrates core full-stack backend capabilities including native HTTP request handling, static file streaming with the Node.js fs module, and complete RESTful CRUD APIs using Express.js.

Available Endpoints

GET /home - Static Home Page (served using fs.readFile)
GET /tasks - List all employee tasks (JSON format)
GET /about - Application description & system info
POST /add-task - Add new task (Node.js HTTP Server)
